     5→// SQLite-compatible (dev). For PostgreSQL (prod), see docs/persistence-model.md
     6→// for type mapping notes. No @db.* decorators used to keep providers swappable.
     7→//
     8→// Conventions (see ADR-0009, ADR-0012, ADR-0013, ADR-0014):
     9→//   - All tables: id String @id @default(cuid())
    10→//   - All tables: createdAt, updatedAt, deletedAt? (soft delete)
    11→//   - All tables: createdBy?, updatedBy? (audit)
    12→//   - Versioned aggregates: version Int @default(1)
    13→//   - Money: amountMinorUnits BigInt + currencyCode String (never Float/Decimal)
    14→//   - JSON stored as Json type (SQLite maps to String internally)
    15→//   - Foreign keys: RESTRICT by default, SET NULL for optional
    16→//
