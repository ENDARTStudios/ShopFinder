# PROMPT MESTRE AUTÔNOMO — Protocolo Thinker/Doer

## Visão Geral
Protocolo para desenvolvimento autônomo de software com papéis definidos:
- **Thinker**: Estratégia, planejamento e decisões
- **Doer**: Execução física de código e comandos
- **Operador**: Validação e supervisão humana

## Ciclo TAREFA → STATUS → REVIEW
1. Thinker emite TAREFA com especificação clara
2. Doer executa e emite STATUS (DONE/BLOCKED/PARCIAL)
3. Thinker faz REVIEW (APPROVED/REJECTED/BLOCKED)

## Termos Contratuais
- /spec: Especificação da tarefa
- /build: Execução do código
- /review: Validação do resultado
